# Post 2 — LinkedIn (launch day)

> The held-out oracle is the only thing standing between your coding agent and
> the SWE-bench false-green problem.
>
> Every "I'm done" from an agent deserves a single question: *done according to
> whom?* If the check script's cases are visible to the agent, it will fit
> them — and fail everything else.
>
> We built AgentLoop (open source, MIT) around one idea: grade the agent on a
> sealed, held-out set of inputs it never saw. On SWE-bench-Verified that
> took resolve rates from ~64% → 80% for Claude Code and ~58% → 80% for
> OpenCode — with the same models, the same prompts, just an oracle that can
> say "no" with evidence.
>
